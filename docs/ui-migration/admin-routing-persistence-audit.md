## Current route architecture

- UI-Router is a singleton; state modules are centrally imported and registered. The push-state base comes from `VITE_APP_BASE_URL`. Retain state names and parameter contracts while making the Elements entry/base explicit. Avoid importing the complete legacy state registry into the new entry: it registers legacy page implementations. Sources: [router singleton](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Router/index.jsx:1), [setup](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Router/setup.jsx:11), [registry](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Router/states.jsx:159).
- The React router wrapper installs global transition hooks around its children. `RouterView` is UI-Router's `UIView`. Nested record layouts already exist: Template owns its PageLayout/header/actions and a child RouterView; its parent state resolves the record, lock metadata and access-related information before rendering. Sources: [wrapper](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Router/RouterWrapper/index.jsx:12), [Template layout](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Template/index.jsx:368), [parent resolves](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Template/state.jsx:20).
- The route configuration can hand individual destinations to Angular. An onBefore hook reads cached `/app-config/index.json`, aborts the React transition and changes `window.location.href` after interpolating parameters. The configured base also controls this asset URL, so changing only the router base would change where configuration is requested. Preserve this handoff deliberately; it cannot share an in-document persistent shell. Source: [redirect adapter](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Router/routerAppRedirect/index.jsx:3).
- Explicit central access checks exist for Gecko AI management routes; they inspect account routing ID and user abilities and redirect denied entry to Settings. Initial destinations vary by call/chat agent abilities, including an Angular campaign redirect. API-backed route resolves provide additional access enforcement; the local routing guidance explicitly says rejected resolves should prevent entry. Sources: [guards and defaults](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Router/setup.jsx:21), [routing guidance](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/.agents/skills/gecko-admin-development/references/routing.md:7).

## Pilot selection evidence

The candidate **Templates list → existing record Settings → Editor → Usage → return to list** pilot is supported by the following source evidence. It directly exercises the historical wrong-title/wrong-editor/action risk, shared parent record data, child routes, lock-dependent actions, filter persistence and unsaved navigation.

Evidence:

- [List route](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Templates/state.jsx:42) has keyword, pagination, sorting, type, category and lock filters and requests name/type/editor metadata.
- [Record route](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Template/state.jsx:20) resolves record and lock information at the parent; Usage has separate paginated data.
- [Editor selection](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Template/Components/Editor/index.jsx:19) depends on both template type and editor type; a generic editor must never be rendered while either is unknown.
- [Shared header](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Template/index.jsx:93) uses the resolved name; [actions](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Template/index.jsx:278) include clone, test email, download, lock, delete, Save and WhatsApp approval variants. Save uses an EventBus bridge into the active child editor, which needs explicit preservation or replacement at the application boundary.

This is a meaningful but nontrivial pilot. If the user selects Templates, start the navigation proof with an existing plain SMS/basic template; do not label the whole Templates workflow migrated until other editor types, locks, approval states and actions pass their parity records. Hosts is a smaller list/edit smoke test with clean Commands and save/delete flows, but no child record tabs, so it cannot alone prove the central persistence requirement: [Host route](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Host/state.tsx:6), [Host save/delete](/Users/liamyoung/Repos/Gecko-Admin-Web-App/App/src/Modules/Host/index.tsx:63).
