# Gecko Elements agent guidance

For component implementation, documentation or product usage in any workspace, start with the [@geckolabs/elements usage guide](packages/ui/README.md), then read the matching component contract before making changes. The guide defines the desktop-only application scope.

Before adding, replacing or directly importing an external UI dependency, read `packages/ui/docs/dependencies.md`. Reuse the approved `@geckolabs/elements` interface and its assigned implementation dependency.

For Admin-to-Elements migration planning, implementation, review or handover, start with [the migration plan](docs/ui-migration/README.md). It owns scope, decisions, current progress and the next step; follow its reading order. Reports under `docs/ui-migration/snapshots/` are historical evidence, not current instructions.
