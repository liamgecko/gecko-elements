# Gecko Elements agent guidance

For component implementation, documentation or product usage in any workspace, start with the [@gecko/ui usage guide](packages/ui/README.md), then read the matching component contract before making changes. The guide defines the desktop-only application scope.

Before adding, replacing or directly importing an external UI dependency, read `packages/ui/docs/dependencies.md`. Reuse the approved `@gecko/ui` interface and its assigned implementation dependency.
